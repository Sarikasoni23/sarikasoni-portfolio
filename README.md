## About

The portfolio presents my development experience, technical skills, projects, GitHub activity, and contact information in a responsive web interface.

## Tech Stack

- Next.js
- React.js
- JavaScript
- CSS
- Notion API client
- React GitHub Calendar
- Vercel deployment

## Available Scripts

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Run the production build:

```bash
npm start
```

## Project Structure

- `components/` — reusable interface components
- `pages/` — Next.js routes/pages
- `public/` — static assets
- `styles/` — application styling
- `next.config.js` — Next.js configuration
